
## About Me :

#### Hello!

Projects:

- <a href="https://lustrous-churros-6ae756.netlify.app/home">Multimarket<a/> - E-comm platform that implements the working principle of a marketplace. Stack: JavaScript, ReactJS, React Hooks, Redux Toolkit, React Router Dom, SCSS, Reactstrap, React-Toastify (for informing the user about actions), Firebase for storing data about products and users. Authorization is also implemented in the project. The application is fully adapted to all devices https://github.com/homie43/ecom-shop

- <a href="https://pizza-delivery-three.vercel.app/">Pizza Delivery<a/> - frontend application that implements the working principle of pizza delivery 😏. Stack: TypeScript, ReactJS, React Hooks, Redux Toolkit, React Router Dom, Axios, SCSS, mockApi for storing data about pizza. https://github.com/homie43/pizza-delivery

- <a href="https://homie43.github.io/hacker-news/">Hacker News</a> - my version of the interface for the <a href="https://news.ycombinator.com/news">Hacker News</a> website. Stack: ReactJS, React Hooks, React Router Dom, Axios, SCSS, Redux, react-lazyload, Hacker News API, yarn. https://github.com/homie43/hacker-news
